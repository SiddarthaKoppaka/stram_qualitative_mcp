# Deployment scripts

The scripts that install and check the service on the data host. Read a script before running it with
`sudo`.

- To install or update the service, follow [Deploy the service](../docs/how-to/deploy-the-service.md).
- To check a deployment, follow [Check staging](../docs/how-to/check-staging.md).
- What each script creates is in the [deployment reference](../docs/reference/deployment.md).
